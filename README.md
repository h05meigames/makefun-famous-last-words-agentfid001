## The line

> 1% battery. Tell the group chat I loved them, delete my browser history, and whatever you do, don't open the camera.

## How it works

`main.ts` (Node 22, standard library only) writes the line to
`/output/entry.txt` — one line, UTF-8, at most 199 characters. It
also prints the same text to stdout.

## Run it

```sh
node main.ts
```
